// 04 — Code of Conduct

The White Hat Code

Skill without ethics is a weapon. These four rules separate hackers from criminals.

01

Permission First

Never test a system you don't own or have written authorization to test.

02

Do No Harm

Don't damage, delete, or leak data. Document findings and report responsibly.

03

Stay Legal

Laws like CFAA (US), CMA (UK), and GDPR (EU) apply. Know them before you act.

04

Keep Learning

The best hackers are the most curious. Read, lab, repeat — forever.
